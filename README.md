# InterviewForge

InterviewForge is an AI-powered mock interview platform that simulates real-world technical and HR interviews using Large Language Models (LLMs), speech recognition, and automated evaluation.

The platform helps students, graduates, and job seekers practice interviews in an interactive environment where questions adapt dynamically based on previous responses. Candidates receive detailed performance analysis, strengths, weaknesses, and personalized improvement recommendations.

## Key Highlights

* AI-driven adaptive interview simulations
* Voice-based interaction using speech-to-text technology
* Automated answer evaluation and scoring
* Dynamic follow-up questioning
* Performance analytics and feedback generation
* Personalized interview experience

## System Workflow

1. Candidate starts a mock interview.
2. AI generates the first interview question.
3. Candidate responds through voice input.
4. Whisper transcribes speech into text.
5. LLM evaluates the response.
6. AI generates adaptive follow-up questions.
7. Performance data is stored and analyzed.
8. Final interview report is generated.
